# guiomarniso.com

Personal website of Guiomar Niso, built with Jekyll and published with GitHub Pages.

## How to edit

You can edit everything from the GitHub website: open a file, click the pencil icon, change it and click "Commit changes". The site rebuilds itself in about a minute.

| What you want to change | File |
|---|---|
| Positions, education, awards | `_data/vitae.yml` |
| Publications | `_data/publications.yml` |
| Open science initiatives | `_data/initiatives.yml` |
| Media appearances | `_data/media.yml` |
| Biography and home page | `index.html` |
| Contact details | `contact.html` and `_includes/footer.html` |
| Menu | `_config.yml` |
| Colours and fonts | `assets/css/main.css` (top of the file) |

Images live in `assets/img/` (your photo is `guiomar-niso.jpg`, logos are in `assets/img/logos/`).

To add a publication, copy an existing block in `_data/publications.yml`, paste it at the top and change the fields. Keep the two spaces of indentation.

## The brain-rhythm graphic

The five traces in the home page are generated by `tools/make_signal.py`, which writes `_includes/signal.html`.
